## TP6 — Base de datos y normalización

El proyecto utiliza una base de datos independiente llamada `acp_proyecto`. Su estructura se encuentra en `database/schema.sql` y las consultas de práctica, en `database/consultas.sql`. El esquema contiene `usuarios`, `estados_revision` y `evaluaciones`, vinculadas mediante claves primarias y foráneas. La normalización evita repetir información de usuarios y estados en cada evaluación.
